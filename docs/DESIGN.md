# Toogeduler 디자인 원칙

최종 갱신: 2026-10-18 · 디자이너 에이전트와 사람이 화면을 만들 때 기준으로 삼는다. 바꾸려면 PR로.

## 한 가지 생각: 겹치는 필름
사람마다 투명한 색 필름이 한 장씩 있다. 일정이나 빈 시간이 겹치면 필름이 겹쳐(`mix-blend-mode: multiply`) 저절로 진해진다. 앱 아이콘(두 사각형이 겹치는 모양)과 같은 생각이다.

- 겹침은 **정보**다. 누가 언제 바쁜지, 언제 모두 되는지를 색이 겹치는 정도로 보여준다. 장식으로 필름을 뿌리지 않는다.
- 이 앱에서 대담한 것은 필름 하나뿐이다. 나머지는 조용하게 둔다.

## 색 (`web/app/globals.css`의 `:root`)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | `#141a26` | 글자, 그리고 **유일한 행동 색**(주 버튼) |
| `--ink-2`, `--muted`, `--faint` | | 보조 글자 단계 |
| `--line`, `--line-soft` | `#e5e7eb`, `#f0f1f3` | 구분선, 빈 트랙 |
| `--canvas` | `#f6f6f7` | 옅은 중성 회색 바탕 |
| `--film-cyan`, `--film-magenta` | `#19a5d0`, `#e2497f` | 브랜드 필름 |
| `--overlap` | `#5a67a6` | 필름 두 장이 겹친 색. "모두 돼요" |

- 일정·사람 색은 저장된 값(`#168CF2 #19B7B1 #8B6FF7 #F0648C #F29E38`)을 그대로 쓰고, 그릴 때 필름으로 바꾼다: 배경 `color-mix(var(--c) 22~26%, transparent)` + multiply, 글자 `color-mix(var(--c) 42%, var(--ink))`.
- 푸른 회색, 청록 주 버튼, 그라데이션 배경은 쓰지 않는다.

## 서체
- **Wanted Sans Variable** 한 가족. 큰 제목은 굵게(800)와 좁은 자간(-0.04em), 숫자는 `tabular-nums`.

## 구조
- 그림자 대신 가는 선(`1px solid var(--line)`). 그림자는 겹쳐 뜨는 창(모달·서랍)의 `--shadow-overlay` 하나뿐.
- 모서리는 작게: 컨트롤 6~8px, 패널 10~14px, 필름 사각형은 4~6px.
- 사람 얼굴은 동그라미가 아니라 둥근 사각 필름.
- 정보 묶음은 카드를 쌓지 말고 선으로 나눈 한 장으로(마이페이지 참고).

## 하지 않는 것 (흔한 "AI가 만든 화면" 티)
- 제목 위의 작은 라벨("반가워요" 같은 kicker)
- 그라데이션 배너, 장식용 원·지구본
- 모든 블록을 같은 둥근 카드 + 옅은 그림자로 감싸기
- 아이콘 타일 + 숫자로 된 통계 카드
- 일정 왼쪽 색 띠

## 확인
- 화면을 바꾸면 데스크톱(1280)과 휴대폰(375) 캡처로 확인한다. 휴대폰 터치 영역은 44px 이상.
